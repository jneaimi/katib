# polaroid-wall

**Tier:** section

## Purpose

Scrapbook-style scattered Polaroid wall — 7 photos with white frames, slight rotations, and natural overlap. Optional center handwritten-note element. Bilingual EN+AR. Designed for editorial photo essays, year-in-review posts, casual feature spreads.
