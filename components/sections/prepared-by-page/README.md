# prepared-by-page

**Tier:** section

## Purpose

Standalone signature title page for proposals. Centred proposal title block (eyebrow, title, reference), a Prepared-by table with printed and blank ruled fields plus an optional signature and company-stamp image, and a for-and-on-behalf-of company line. Fills its own page.
